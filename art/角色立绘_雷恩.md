# 雷恩（Rain）角色立绘设计表

## 基本信息
- **姓名**：雷恩（Rain）
- **年龄**：28岁
- **职业**：神秘组织"守望者"的成员
- **身高**：182cm

## 服装系列

### 1. 战术服装（工作）
- **外观描述**：
  - 黑色战术装备
  - 多功能口袋（战术背心）
  - 武器装备（枪械、刀具）
  - 护目镜（可选）
  - 黑色战术靴
- **发型**：黑色短发，有些凌乱
- **表情**：简洁、有力、不轻易表达情感
- **场景**：秘密任务、对抗时间领主
- **配色方案**：黑色、深绿色
- **风格**：战术、专业、神秘

### 2. 休闲服装
- **外观描述**：
  - 黑色T恤
  - 深色牛仔裤
  - 休闲运动鞋
  - 简约配饰
- **发型**：黑色短发，略微凌乱
- **表情**：内敛、沉稳、偶尔流露真实情感
- **场景**：咖啡馆、日常休闲
- **配色方案**：黑色、深绿色
- **风格**：简约、沉稳、内敛

### 3. 失眠服装
- **外观描述**：
  - 深绿色运动服
  - 柔和的材质
  - 淡绿色光环
- **发型**：黑色短发，更加凌乱
- **表情**：疲惫、幻觉、模糊
- **瞳孔**：深绿色，失眠时身体散发出淡淡绿色光芒
- **特殊标志**：失眠时身体会散发出淡淡的绿色光芒
- **场景**：失眠状态、战斗中
- **配色方案**：深绿色、黑色
- **风格**：柔和、疲惫、神秘

### 4. 战斗服装（可选）
- **外观描述**：
  - 黑色战斗服
  - 能量护甲
  - 武器装备
  - 战术护目镜
- **发型**：黑色短发
- **表情**：严肃、坚定、决心
- **瞳孔**：深绿色，发光
- **场景**：对抗时间领主
- **配色方案**：黑色、深绿色、蓝色能量
- **风格**：战斗感、专业、神秘

## 表情系列

### 正常状态表情
1. **简洁有力**：不轻易表达情感，直接
2. **沉稳内敛**：保持冷静，不轻易流露
3. **坚定决心**：认定的目标，坚持
4. **疑惑询问**：对未知事物，好奇但谨慎
5. **温柔关怀**：关心他人，内敛但真诚

### 失眠状态表情
1. **疲惫迷茫**：实验事故后，疲惫迷茫
2. **幻觉中**：看到时间碎片或时空裂缝
3. **痛苦挣扎**：失眠带来的痛苦
4. **模糊对话**：对话变得模糊，意识混乱
5. **空洞凝视**：失去焦点，时间感知失调

### 情感状态表情
1. **坚定决心**：认定的目标，坚持
2. **温柔关怀**：关心他人，内敛但真诚
3. **悲伤失落**：失去重要的人
4. **坚定安慰**：安慰他人，内敛但有力
5. **真诚微笑**：偶尔流露的真诚微笑

### 严肃状态表情
1. **严肃认真**：面对重要决策
2. **坚定有力**：展现决心
3. **深思熟虑**：分析复杂情况
4. **威严自信**：展现专业权威
5. **冷静沉着**：应对危机

## 设计原则

### 一致性
- 所有服装和表情符合角色性格
- 配色方案统一协调
- 角色特征保持一致

### 多样性
- 服装系列丰富，适应不同场景
- 表情系列完整，覆盖所有情绪状态
- 场景多样，展现角色不同侧面

### 深度
- 表情传达角色内心情感
- 服装反映角色状态变化
- 场景烘托角色情感和氛围

### 艺术风格
- 整体风格：现代日式视觉小说风格
- 线条：硬朗流畅
- 色彩：深色调，但失眠时偏柔和
- 光影：硬朗有力，失眠时偏绿

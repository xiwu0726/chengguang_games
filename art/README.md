# 《时光之痕》美术资源设计文档

## 项目概述
本项目为视觉小说《时光之痕》的美术资源设计文档，包含角色立绘设计、场景设计、UI界面设计等内容。

## 文档结构

### 角色立绘设计
- **角色立绘_林晓.md** - 主角林晓的详细设计，包括服装系列、表情系列、颜色方案、角色特征等
- **角色立绘_艾莉丝.md** - 艾莉丝的详细设计，包括服装系列、表情系列、颜色方案、角色特征等
- **角色立绘_雷恩.md** - 雷恩的详细设计，包括服装系列、表情系列、颜色方案、角色特征等
- **角色立绘_小雅.md** - 小雅的详细设计，包括服装系列、表情系列、颜色方案、角色特征等
- **角色立绘_时间领主.md** - 反派时间领主的详细设计，包括服装系列、表情系列、颜色方案、角色特征等

### 场景设计
- **场景设计_新东京.md** - 主时间线城市新东京的详细设计，包括城市概览、主要区域、时间变化、艺术风格等
- **场景设计_时空研究所.md** - 时空研究所的详细设计，包括入口大厅、实验室、数据中心、观测室等

- **UI界面设计.md** - 整体UI设计规范，包括配色方案、字体设计、界面布局、交互设计、特殊界面、界面特效、动画设计等

## 设计原则

### 1. 一致性
- 所有角色、场景、UI保持统一的设计语言
- 配色方案统一协调
- 字体风格统一
- 交互方式统一

### 2. 多样性
- 角色服装系列丰富，适应不同场景
- 角色表情系列完整，覆盖所有情绪状态
- 场景多样，展现角色不同侧面
- UI设计丰富，功能明确

### 3. 深度
- 表情传达角色内心情感
- 服装反映角色状态变化
- 场景烘托角色情感和氛围
- UI设计符合角色性格和故事主题

### 4. 艺术风格
- 整体风格：现代日式视觉小说风格
- 线条：流畅自然
- 色彩：明亮温暖，但特殊状态偏冷
- 光影：自然柔和，特殊状态强烈对比

## 核心概念

### 1. 角色设计
- **林晓**：主角，历史系研究生，获得时间碎片感知能力，失眠时瞳孔变为淡蓝色
- **艾莉丝**：时空异常研究所研究员，银色长发，失眠时眼睛会微微发光
- **雷恩**：守望者组织成员，黑色战术装备，失眠时身体散发出淡淡的绿色光芒
- **小雅**：咖啡馆店员，粉色长发，失眠时头发会微微发光
- **时间领主**：反派，林晓的未来自己，银色长发，全身散发出时间碎片的光芒

### 2. 场景设计
- **新东京**：2150年主时间线，科技与传统的完美融合，时空裂缝频繁出现
- **时空研究所**：研究时空现象、开发时间碎片技术的专业机构
- **历史图书馆**：保存古代书籍、现代资料、秘密档案、时空文献的宏伟图书馆
- **咖啡馆（时间角落）**：主角团队聚集地，可以看到不同时间线的痕迹

### 3. 核心特效
- **时间碎片光芒**：淡蓝色、淡紫色光芒，代表时间碎片
- **时空裂缝痕迹**：紫色、粉色、蓝色交织的痕迹，代表时空裂缝
- **失眠特效**：不同角色有不同颜色的发光效果（林晓淡蓝色、艾莉丝深蓝色发光、雷恩深绿色发光、小雅淡粉色发光）
- **意识流效果**：对话框模糊、角色立绘模糊，代表失眠状态
- **空间扭曲效果**：角色立绘变形、背景扭曲，代表时间线切换

## 配色方案

### 主色调
- **蓝色系**：科技、时间、冷静（主蓝色 #4A90E2、淡蓝色 #87CEEB、深蓝色 #2C3E50）
- **紫色系**：神秘、时间领主、时空裂缝（主紫色 #9B59B6、淡紫色 #D8BFD8、深紫色 #4B0082）
- **粉色系**：小雅、艺术、柔和（主粉色 #FF69B4、淡粉色 #FFB6C1、深粉色 #FF1493）

### 辅助色
- **白色**：#FFFFFF（背景、文字）
- **灰色**：#F5F5F5（界面背景）、#CCCCCC（边框）
- **黑色**：#000000（文字、边框）

## 开发建议

### 1. 角色立绘开发顺序
- 先开发主要角色（林晓、艾莉丝）的基础立绘
- 然后开发表情系列
- 再开发服装系列
- 最后开发特殊状态（失眠、战斗）立绘

### 2. 场景开发顺序
- 先开发主要场景（新东京、时空研究所、历史图书馆、咖啡馆）
- 然后开发场景内部细节
- 最后开发特殊场景（时空裂缝出现、实验事故）

### 3. UI开发顺序
- 先开发主界面和对话框
- 然后开发各种系统界面
- 最后开发特殊界面（失眠状态、时间线切换、记忆碎片收集、多结局）

### 4. 特效开发顺序
- 先开发基础特效（时间碎片光芒、时空裂缝痕迹）
- 然后开发角色发光特效
- 最后开发特殊效果（意识流、空间扭曲）

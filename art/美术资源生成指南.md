## 制作建议

### 1. 使用AI图像生成工具
- **Stable Diffusion**：使用以下提示词
  ```
  [提示词]，现代日式视觉小说风格，高质量，高清，细节丰富，1920x1080
  ```

- **Midjourney**：使用以下提示词
  ```
  [提示词] --style raw --ar 16:9 --v 5.2
  ```

- **DALL-E**：使用以下提示词
  ```
  [提示词]，现代日式视觉小说风格，高质量，高清，细节丰富，1920x1080
  ```

### 2. 图像编辑
- 使用Photoshop或GIMP调整尺寸和分辨率
- 调整色彩和亮度
- 添加发光特效
- 裁剪和优化
- 保存为PNG格式

### 3. 特效制作
- 使用After Effects或Premiere Pro创建特效动画
- 导出为PNG序列
- 合成为静态图像
- 保存为PNG格式

### 4. 文件命名规范
- 使用下划线分隔单词
- 使用小写字母
- 使用英文或拼音
- 例如：林晓_日常_温和微笑.png

### 5. 质量控制
- 检查分辨率是否符合要求
- 检查格式是否正确（PNG/JPG）
- 检查风格是否一致
- 检查色彩是否准确
- 检查细节是否丰富

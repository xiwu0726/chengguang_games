**实际的AI图像生成需要使用专门的AI图像生成工具**，如：

- **Stable Diffusion**（开源、免费、可控性强）
- **Midjourney**（质量高、风格统一、易于使用）
- **DALL-E**（OpenAI提供的AI图像生成工具）

这些工具需要单独安装和配置，并且需要用户手动运行。

### 如何使用本任务提供的文档

#### 步骤1：选择AI图像生成工具

根据您的需求和条件选择合适的工具：

- **如果需要免费、开源、可控性强**：选择Stable Diffusion
- **如果需要高质量、风格统一、易于使用**：选择Midjourney
- **如果需要简单易用、不需要安装**：选择DALL-E

#### 步骤2：参考制作指南

打开 `art/美术资源生成指南.md`，查看详细的提示词。

例如，要生成林晓_日常_温和微笑.png：

1. 打开 `art/美术资源生成指南.md`
2. 找到"林晓_日常_温和微笑.png"的提示词
3. 将提示词复制到AI图像生成工具中
4. 设置参数（分辨率、风格等）
5. 生成图像
6. 保存到 `art/角色立绘/林晓/` 目录

#### 步骤3：使用图像编辑工具优化

使用Photoshop、GIMP等图像编辑工具：

1. 调整尺寸和分辨率
2. 调整色彩和亮度
3. 添加发光特效
4. 裁剪和优化
5. 保存为PNG格式

#### 步骤4：更新进度跟踪

打开 `art/制作进度跟踪.md`，更新对应资源的完成状态。

例如：

```markdown
- [x] 林晓_日常_温和微笑.png
```

#### 步骤5：重复上述步骤

按照制作指南和进度跟踪文档，逐步完成所有资源的制作。

#### Stable Diffusion

```markdown

```

**参数建议：**
- 分辨率：1920x1080
- 风格：现代日式视觉小说风格
- 质量参数：high quality, detailed, sharp
- 采样步数：30-50
- CFG Scale：7-12

#### Midjourney

```markdown
使用以下提示词：

[提示词] --style raw --ar 16:9 --v 5.2

例如：

林晓，日常服装（白色T恤、深蓝色牛仔裤、运动鞋），温和微笑的表情，新东京街道背景，现代日式视觉小说风格 --style raw --ar 16:9 --v 5.2
```

**参数建议：**
- 风格：--style raw（raw style，减少风格化）
- 宽高比：--ar 16:9（16:9宽屏）
- 版本：--v 5.2（最新版本）
- 镜像：--no（不包含某些元素）

### 文件命名规范

所有资源文件使用以下命名规范：

```
[角色名]_[服装/状态]_[表情/场景].png

例如：
- 林晓_日常_温和微笑.png
- 艾莉丝_工作_专业专注.png
- 新东京_白天_城市街道.png
- UI_主界面.png
- 林晓_失眠瞳孔特效.png
```

**命名规则：**
1. 使用下划线分隔单词
2. 使用小写字母
3. 使用英文或拼音
4. 使用描述性的名称

### 常见问题

#### Q1：AI图像生成质量不稳定怎么办？

**A：**
- 多次生成，选择最佳结果
- 使用图像编辑工具优化
- 调整提示词参数
- 增加生成次数

#### Q2：资源风格不一致怎么办？

**A：**
- 保持设计文档的指导
- 定期检查资源一致性
- 建立风格参考库
- 使用相同的提示词模板

#### Q3：文件管理混乱怎么办？

**A：**
- 使用清晰的文件命名规范
- 使用分类目录
- 定期备份
- 使用版本管理工具

#### Q4：时间估算不准确怎么办？

**A：**
- 定期检查进度
- 及时调整计划
- 优先完成高优先级资源
- 合理分配时间

#### Q5：如何确保所有资源质量一致？

**A：**
- 使用相同的提示词模板
- 使用相同的图像编辑流程
- 定期进行质量检查
- 建立风格参考库

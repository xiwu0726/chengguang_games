# 语音配音录制指南

## 文档信息
- **项目名称**: 《时光之痕》
- **文档版本**: 1.0
- **创建日期**: 2024年
- **目标**: 指导专业声优进行角色配音录制

---

## 📋 录制准备

### 1. 录音设备
- [ ] **麦克风**:
  - 类型: 专业电容麦克风 (如 Neumann U87, Audio-Technica AT2020)
  - 灵敏度: -48dB 到 -20dB
  - 频响: 20Hz - 20kHz

- [ ] **音频接口**:
  - 采样率: 44.1kHz
  - 位数: 24-bit
  - 输入通道: 至少1个

- [ ] **监听设备**:
  - 耳机: 专业监听耳机 (如 Sony MDR-7506, Audio-Technica ATH-M50x)
  - 音箱: 专业监听音箱 (如 Yamaha HS5, KRK Rokit)

- [ ] **软件**:
  - DAW: Ableton Live, Logic Pro, Pro Tools, 或 Reaper
  - 录音软件: Audacity (备选)

### 2. 录音环境
- [ ] **隔音**:
  - 密闭房间
  - 吸音材料 (吸音棉、吸音板)
  - 避免硬反射表面

- [ ] **声学处理**:
  - 声学吸音: 悬挂吸音棉、地毯、窗帘
  - 声学扩散: 扩散板、扩散体
  - 声学均衡: 调整房间声学特性

- [ ] **温度控制**:
  - 适宜温度: 20-25°C
  - 适宜湿度: 40-60%
  - 避免极端温度和湿度

### 3. 声优准备
- [ ] **角色理解**:
  - 阅读完整剧本
  - 理解角色背景和动机
  - 理解角色关系

- [ ] **情感准备**:
  - 准备不同情感状态
  - 练习角色语气和语调
  - 理解情感变化

- [ ] **身体准备**:
  - 充足睡眠
  - 保持水分
  - 避免刺激性食物和饮料

---

## 🎙️ 录制流程

### 1. 录音前准备

#### 声优准备
```
1. 检查麦克风设置
2. 调整录音环境
3. 进行声学测试
4. 进行麦克风校准
5. 进行音量校准
6. 进行音质检查
```

#### 录音前测试
- [ ] 进行短音测试 (5-10秒)
- [ ] 检查音量水平
- [ ] 检查音质
- [ ] 检查延迟
- [ ] 检查噪音

### 2. 录音过程

#### 基本录制
```
1. 声优就位
2. 选择合适的麦克风距离
3. 调整麦克风角度
4. 调整音量水平
5. 开始录音
6. 监听录音质量
7. 录制完成后停止
```

#### 多次录制
- [ ] 每句对话录制3-5次
- [ ] 每次录制使用不同情感
- [ ] 记录每次录制的版本
- [ ] 选择最佳版本

#### 情感变化
- [ ] 记录情感变化点
- [ ] 逐步增加情感强度
- [ ] 保持情感一致性
- [ ] 避免过度表演

### 3. 录音后处理

#### 立即检查
- [ ] 检查录音质量
- [ ] 检查音量水平
- [ ] 检查音质
- [ ] 检查噪音
- [ ] 确认录音完成

#### 后期处理
- [ ] 去除噪音
- [ ] 调整音量
- [ ] 调整均衡
- [ ] 添加混响
- [ ] 添加压缩
- [ ] 最终混音

## 📝 录制规范

### 1. 音频规格

#### 格式要求
```
格式: WAV
采样率: 44.1kHz
位数: 16-bit 或 24-bit
声道: 单声道 或 立体声
```

#### 文件命名
```
格式: Voice_[角色]_[场景/对话].wav
示例:
- Voice_LinXiao_Intro.wav
- Voice_Alice_Sad.wav
- Voice_Rain_Tension.wav
```

#### 文件位置
```
路径: Assets/Audio/Voices/
```

### 2. 录音参数

#### 音量水平
```
峰值: -6dB 到 -3dB
平均值: -12dB 到 -9dB
避免削波: 确保无削波
```

#### 麦克风距离
```
近距: 5-10cm (柔和、亲密)
中距: 10-20cm (正常、自然)
远距: 20-30cm (大声、强烈)
```

#### 麦克风角度
```
正对: 直接、清晰
侧对: 柔和、温暖
45度: 平衡、自然
```

### 3. 录音质量标准

#### 音质要求
- [ ] 清晰可听
- [ ] 无明显噪音
- [ ] 无明显爆音
- [ ] 无明显延迟
- [ ] 无明显回声

#### 音色要求
- [ ] 符合角色设定
- [ ] 音色统一
- [ ] 音色自然
- [ ] 音色有辨识度

#### 情感要求
- [ ] 情感准确
- [ ] 情感自然
- [ ] 情感连贯
- [ ] 情感有层次
